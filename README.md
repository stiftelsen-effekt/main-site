# Moved to effekt-platform

This repository is archived. The website (gieffektivt.no, giveffektivt.dk and geeffektivt.se) now lives
in [`apps/web` in stiftelsen-effekt/effekt-platform](https://github.com/stiftelsen-effekt/effekt-platform/tree/main/apps/web),
together with the backend and the admin panel. Its full git history was imported there, so
`git log --follow` and blame work as before.

Open new issues and pull requests in [effekt-platform](https://github.com/stiftelsen-effekt/effekt-platform).
The cutover is documented in
[docs/monorepo-cutover.md](https://github.com/stiftelsen-effekt/effekt-platform/blob/main/docs/monorepo-cutover.md).
